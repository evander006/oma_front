# Бэклог

- [x] **Секонд-хэнд** (демо, локально на устройстве; дальше — фото вещей, чат с покупателем, бэкенд) — перепродажа своих вещей, которые уже есть дома: выбрать товар из покупок / паспорта дома (мебель, техника, инструмент, остатки стройматериалов), указать состояние и цену, выставить объявление; другие пользователи могут купить б/у.
