# ОМА · Цифровой дом — единое демоприложение для хакатона

Это **отдельный, неофициальный Android APK**, который воспроизводит структуру
профиля ОМА по скриншотам. **Он не изменяет официальный APK, не использует
настоящую авторизацию и не получает реальные покупки клиентов ОМА**.

## Сценарий

1. Открыть APK и выбрать нижнюю вкладку «Профиль».
2. **До демо-регистрации** строки «Цифровой дом» нет.
3. Нажать «Войти или зарегистрироваться», указать любое демонстрационное имя
   и demo-email, а также создать четырёхзначный код демо-входа. Это локальный
   профиль устройства: настоящий пароль и сессия ОМА не используются.
4. После входа первым пунктом в блоке «Личный кабинет» появляется стандартная
   строка **«Цифровой дом»**. Дизайн этого и прочих пунктов — однострочное
   меню, тонкие пиктограммы, обычные разделители и нижняя навигация из 5 вкладок.
5. В «Цифровой дом» четыре раздела:
   - **3D-модель**: квартира + интерактивная веб-сцена Backend;
   - **Паспорт жилья**: PDF по данным квартиры;
   - **Мой мастер**: каталог подрядчиков, заявка, демо-кабинет мастера
     (можно переключаться на одном телефоне), предложение материала;
   - **Умный поиск**: товары по тексту / визуальный поиск по фотографии
     (ИИ при наличии настроенного провайдера Backend, иначе сравнение по цветам).
6. После выхода можно повторно войти с тем же демонстрационным email и кодом.
   Код не отправляется на сервер. Вкладки «Вход» и «Регистрация» стилизованы
   под меню ОМА: оранжевый индикатор, белые поля и синяя кнопка.
7. «Моя информация» позволяет задать HTTPS-адрес FastAPI и выйти из демо-аккаунта;
   после выхода строка «Цифровой дом» исчезнет.

## Backend

Для рабочих запросов нужен один доступный HTTPS-сервер с веткой
`evander006/oma_be:codex/digital-home-ecosystem`. По умолчанию установлен
`https://oma-be-85l2.onrender.com`, но новая версия на нём не подтверждена.

API: `/api/v1/properties`, `/scene/view/{id}`, `/properties/{id}/passport.pdf`,
`/contractors`, `/work-orders`, `/contractor/work-orders`,
`/products`, `/visual-search`.

Backend использует **общий демонстрационный аккаунт без авторизации**. Вводить
реальные персональные данные запрещено. Демонстрационная корзина и покупки
**не синхронизируются с официальной ОМА**.

## Сборка

JDK 17, Android SDK 35, Gradle 8.9. Запуск из корня:
```sh
gradle -p android_companion :app:assembleDebug
```
APK: `android_companion/app/build/outputs/apk/debug/app-debug.apk`.

В GitHub Actions есть workflow «Build OMA Digital Home unified demo APK»,
который собирает ZIP artifact `oma-unified-demo-debug-apk`.

Package ID: `by.oma.digitalhome.demo`, Android 8.0+. Версия `0.3.0`.

Внимание: APK от разных запусков GitHub Actions могут быть подписаны разными
отладочными ключами. Если обновление не устанавливается, удалите предыдущую
**демоверсию** `by.oma.digitalhome.demo` и установите новую. Это не касается
официального приложения ОМА. Удаление демоверсии сбрасывает локальный вход.
Исходная версия «плавающего окна» остаётся доступна в ветке
`codex/oma-companion-overlay`.
