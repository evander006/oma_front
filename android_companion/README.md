# ОМА · Цифровой дом — единое демоприложение для хакатона

Это **отдельный, неофициальный Android APK**, который воспроизводит структуру
профиля ОМА по скриншотам. **Он не изменяет официальный APK, не использует
настоящую авторизацию и не получает реальные покупки клиентов ОМА**.

## Сценарий

1. Открыть APK и выбрать нижнюю вкладку «Профиль».
2. **До демо-регистрации** строки «Цифровой дом» нет.
3. Нажать «Войти или зарегистрироваться», указать любое демонстрационное имя
   и demo-email, а также создать четырёхзначный код демо-входа. Это локальный
   профиль устройства: настоящий пароль и сессия ОМА не используются.
4. После входа первым пунктом в блоке «Личный кабинет» появляется стандартная
   строка **«Цифровой дом»**. Дизайн этого и прочих пунктов — однострочное
   меню, тонкие пиктограммы, обычные разделители и нижняя навигация из 5 вкладок.
5. В «Цифровой дом» четыре раздела:
   - **3D-модель**: квартира + интерактивная веб-сцена Backend;
   - **Паспорт жилья**: PDF по данным квартиры;
   - **Мой мастер**: каталог подрядчиков, заявка, демо-кабинет мастера
     (можно переключаться на одном телефоне), предложение материала;
   - **Умный поиск**: товары по тексту / визуальный поиск по фотографии
     (ИИ при наличии настроенного провайдера Backend, иначе сравнение по цветам).
6. После выхода можно повторно войти с тем же демонстрационным email и кодом.
   Код не отправляется на сервер. Вкладки «Вход» и «Регистрация» стилизованы
   под меню ОМА: оранжевый индикатор, белые поля и синяя кнопка.
7. «Моя информация» позволяет задать HTTPS-адрес FastAPI и выйти из демо-аккаунта;
   после выхода строка «Цифровой дом» исчезнет.

## 3D-редактор комнаты

- Раздел «3D-модель» открывает реалистичную интерактивную сцену Three.js во встроенном Android WebView вместо прежнего упрощённого OpenGL-макета.
- Комнаты, купленные товары и каталог читаются из локального демо-профиля и встроенной SQLite-базы ОМА (134 266 позиций); искать товары можно по названию, категории, бренду и артикулу.
- Предварительная расстановка сохраняется отдельно от демо-покупок. Можно добавить несколько экземпляров одного товара, перемещать их, поворачивать и убирать; удаление предмета не отменяет заказ.
- Сцена использует физически корректные материалы, текстуры дерева/плитки/штукатурки, окружение, мягкие тени, оконные рамы, шторы и более детальные модели по категориям. Если нет точной GLB-модели производителя, форма остаётся процедурным приближением.
- Для загрузки HTML-сцены нужен backend с маршрутом `/api/v1/scene/editor` и актуальным `scene.html`. Каталог и черновая расстановка в Android-демо не отправляются в официальный аккаунт ОМА.

## Backend

Для рабочих запросов нужен один доступный HTTPS-сервер с веткой
`evander006/oma_be:codex/digital-home-ecosystem`. По умолчанию установлен
`https://oma-be-85l2.onrender.com`, но новая версия на нём не подтверждена.

API: `/api/v1/properties`, `/scene/view/{id}`, `/properties/{id}/passport.pdf`,
`/contractors`, `/work-orders`, `/contractor/work-orders`,
`/products`, `/visual-search`.

Backend использует **общий демонстрационный аккаунт без авторизации**. Вводить
реальные персональные данные запрещено. Демонстрационная корзина и покупки
**не синхронизируются с официальной ОМА**.

## Сборка

JDK 17, Android SDK 35, Gradle 8.9. Запуск из корня:
```sh
gradle -p android_companion :app:assembleDebug
```
APK: `android_companion/app/build/outputs/apk/debug/app-debug.apk`.

В GitHub Actions есть workflow «Build OMA Digital Home unified demo APK»,
который собирает ZIP artifact `oma-unified-demo-debug-apk`.

Package ID: `by.oma.digitalhome.demo`, Android 8.0+. Версия `0.12.0-photo-pdf-fix`.

Внимание: APK от разных запусков GitHub Actions могут быть подписаны разными
отладочными ключами. Если обновление не устанавливается, удалите предыдущую
**демоверсию** `by.oma.digitalhome.demo` и установите новую. Это не касается
официального приложения ОМА. Удаление демоверсии сбрасывает локальный вход.

## Запуск на одном Android-телефоне

1. Включите на телефоне «Для разработчиков» → «Отладка по USB» и подтвердите
   доверие этому компьютеру.
2. Подключите только один Android-телефон и проверьте `adb devices` — у строки
   устройства должен быть статус `device`.
3. Запустите из корня репозитория:

```powershell
.\android_companion\install_on_phone.ps1
```

Скрипт устанавливает готовый `app-debug.apk` с обновлением данных приложения и
запускает `by.oma.digitalhome.demo`. Если подпись старой debug-сборки отличается,
скрипт остановится и объяснит, как вручную удалить только демоверсию. Официальное
приложение ОМА не затрагивается.

## Улучшения версии 0.12.0

- «Просмотреть паспорт PDF»: исправлены параметры просмотра в `HorizontalScrollView`, размер bitmap ограничен для безопасности памяти; ошибки просмотра выводятся в интерфейсе без аварийного завершения.
- «Поиск по фото»: выбор между камерой и галереей через один диалог; фото камеры сохраняется во временный файл приложения через FileProvider.
- Поиск по фото сначала использует встроенный ML Kit для определения общих категорий товаров, затем ищет совпадения по всему импортированному каталогу (134 266 позиций). Доступная серверная vision-модель может уточнить результаты.
- Если автоматическое распознавание не смогло определить категорию, пользователь может указать название предмета, и поиск пройдёт по всему каталогу.
- Важно: на текущем этапе это сопоставление **по распознанным категориям и названиям**, а не по векторному индексу изображений всех 134 тысяч товаров. Проценты не являются уверенностью в точном совпадении артикула.
- Полный каталог устанавливается из APK автоматически; ручной импорт не требуется.

## Вкладки магазина · версия 0.4.0

Обычные пять вкладок магазина теперь заполнены **локальным демофункционалом**:
- **Главная**: логотип, город Минск, поиск, горизонтальные категории, рекламные блоки
  (на текущем этапе текстовые макеты, оригинальные картинки рекламных акций ещё не перенесены),
  карточки товаров.
- **Каталог**: сетка категорий/подкатегорий, товарная выдача по 2 колонки, поиск,
  переключение сортировки, карточка товара с фотографией, ценой, избранным,
  кнопкой корзины и описанием/параметрами.
- **Корзина**: пустое состояние, ранее просмотренные, количество товаров, подсчёт
  суммы, свайп влево с действиями «в избранное» и «удалить», демонстрационное
  оформление без платежей.
- **Избранное**: пустое состояние, добавленные товары и перемещение в корзину.
- **Профиль**: прежние разделы и отдельный пункт «Цифровой дом» после локальной регистрации.
  Экосистему в этом релизе не меняли.

### Встроенный каталог

В APK включена сжатая SQLite-база на **134 266 товаров** из выгрузки
`oma_catalog_20261028_113225`. При первом запуске база автоматически
распаковывается во внутреннюю память приложения и сразу становится доступна
во вкладке «Каталог». Пользователю не нужны дополнительные файлы или импорт.

Карточки без ссылки на фотографию исключаются при сборке базы. Если ссылка
стала недоступна позднее, соответствующая карточка скрывается во время работы.
Реальные наличие, платежи и история заказов ОМА к демоверсии не подключены.

### Быстрый тест

1. После чистой установки открыть «Каталог» и убедиться, что категории доступны без импорта.
2. Перейти в подкатегорию, дождаться фотографий и открыть товар.
3. Добавить товар в корзину и в избранное через кнопки внутри каталога.
4. Открыть «Корзину», изменить количество, свайпнуть карточку влево —
   появятся кнопки избранного и удаления.
5. Проверить пустую и непустую корзину, возвращение к покупкам.
6. Проверить «Услуги», «Мои проекты» и основные действия цифрового дома.

Приложение использует неофициальный локальный демонстрационный каталог.
Официальную ОМА, её платежи или авторизацию оно не изменяет.
