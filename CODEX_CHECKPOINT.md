## Дополнительные дефекты/риски, не исправленные данным коммитом

- RemotePropertiesRepository.save() хранит часть состояния только в local overlay. PropertiesCubit.rename() изменяет имя в памяти, но в backend пока нет PATCH для properties. При перезагрузке имя может не сохраниться сервером. Требуется API-контракт и тесты.
- RemotePropertiesRepository.load() гасит ошибки сети и возвращает [], что маскирует недоступность API под отсутствие объектов. Нужна обработка ошибок.
- AI wizard при пустом результате персональных рекомендаций берёт первые товары каталога. Обязательно подписать это как общую подборку, а не как персональную рекомендацию ИИ.
- Backend цены товаров — снимки по дате сбора, не подтверждённые цены текущей корзины ОМА.

## Почему это хакатонный MVP

Цель — расширить экосистему ОМА за пределы товаров. Основная идея «ОМА. Мой дом»: цифровой паспорт жилья с комнатами/объектами, карточками покупок и обслуживания; связка с AI-дизайном, каталожными товарами, установкой и ремонтом. Критерии жюри: чёткая аудитория/проблема, CJM и целостность, подтверждение конкурентами, преимущество, творчество/масштабирование, монетизация и реалистичная экономика, демонстрация/команда. MVP-функции не путать с концептом.
